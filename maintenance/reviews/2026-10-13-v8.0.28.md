# Upstream v8.0.28 review, 13 October

## Decision and scope

Review target is official stable v8.0.28, commit
`0d18d3b365be000eeaee7de4615f9da596b2059d`, published 14 October 00:41 UTC,
13 October locally. Upstream main matched that tag at fetch. The deployed v6
artifact uses upstream `3de4e248`. This update is a source candidate on
`se/review-v8.0.28`, based on the nearest-reset candidate `eea3ba35`.
It is not a deployed gateway or an enabled quota policy.

The endpoint-to-endpoint upstream diff has 234 files, 21,730 additions and 1,371
deletions, predominantly tests and new opt-in provider capabilities. Review used
the ancestry-path commit list rather than unrelated side-branch history.

## Changes relevant to this fork

- Claude MCP restoration `02fc76b1` recognizes a full caller-owned mcp__ name
  wrapped under the virtual server, preserving tool identity.
- Deferred-tool cache fix `97ba1e89` preserves prompt-cache anchors when tool
  discovery introduces the first deferred tool. New Responses/native tool-search
  translation remains gated by `upstream.claude.tool-search`, default false.
- HTTP/2 lifecycle fix `56eee6a4` treats closed client connections as transient
  transport failures, not credential rejection/cooldown.
- Codex SSE scanner `7795de19` assembles multiline event data, including streaming,
  synchronous, compact and image paths. Numeric-bound correction `57d005fe`
  discards schema bounds outside int64 rather than forwarding invalid tools.
- Runtime configuration fixes `e235fb3d`, `e230a04b` and `81573f04` synchronize
  reload snapshots, handler/plugin configuration and startup state.
- Executor lifecycle `1e37b52b` preserves websocket execution sessions across
  reload/replacement and removes only sessions for an affected credential.
- Routing option `7a687f42` adds session-affinity-rebind-on. Its default "any"
  preserves prior policy; optional "quota" retains the original binding across
  temporary failures. This update does not change the live setting.
- Codex Sign in with ChatGPT adds opt-in SIWC credentials and refresh/persistence
  support. Existing OAuth files remain valid. The new file-lock and merge paths
  preserve newer disk credentials when stale configuration snapshots save.
  Rollback must retain current credentials, never restore an older auth snapshot.
- Request-body limits and pre-first-token heartbeats default off. Catalog changes
  add current models and retire legacy Gemini entries. No new capabilities or
  user-visible guarantees are inferred from catalog presence alone.

## Pull-request comparison

Open PR6562 implements most-remaining selection, passive-only observation, model
limits and bounded unknown-account exploration. That differs from this fork's
nearest shared weekly reset, shared-window-only policy with bounded on-demand
refresh. Do not import a second selector. Its quota-arrival timestamp guard was
adapted in eea3ba35: stream completion cannot freshen old readings, partial events
age untouched fields conservatively, and old completed streams cannot replace new
observations. Tests cover the guard.

Unmerged PR6527 addresses credential-wide usage scope; PR6603 and PR6605 address
concurrent state saves and atomic credential writes. They are watch items, not
accepted patches. Released HTTP/2, SSE, MCP and deferred-cache fixes are taken from
the official tag rather than importing their open/closed PR versions separately.

## Merge and qualification

Three textual conflicts were resolved by retaining both changes:
CodexAutoExecutor quota fetching plus upstream config/session lifecycle methods;
the durable/quota selector plus upstream optional rebinding behavior; and service
wiring for all three. A new upstream fallback branch also passes through the same
quota wrapper. Schema-1 checkpoint/storage implementation is unchanged.

macOS server build and focused auth/service/executor/logging races passed. The
full Mac suite after test-fixture repair passes all packages except the unchanged
multicast discovery integration failure previously reproduced on pristine upstream.
Two executor tests assumed models still existed in the static catalog. Both failed
identically on untouched v8.0.28; explicit temporary model fixtures now restore
their original level-normalization assertions without changing production behavior.
Three-repeat fixture checks passed.

TestResponsesLateInterruptDoesNotPoisonNextCreate failed intermittently in initial
candidate and earlier-base Linux full runs. Twenty isolated candidate repeats and
the untouched v8.0.28 full OpenAI-handler package passed. This is a recorded timing
uncertainty, not a proved fix or a clean acceptance of every interruption path.
No cancellation test was skipped or weakened.

Windows, Linux qualification and independent review are recorded as they finish
in maintenance/qualification.md. Live choice comparison, first-response timing,
real native worker follow-ups and controlled activation remain separate gates.
